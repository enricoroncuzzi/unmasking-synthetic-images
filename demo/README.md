# Unmasking Synthetic Images — Forensic MoE Demo

Upload any image to detect whether it was generated by AI and identify which
Stable Diffusion variant produced it.

**How it works:** five ResNet50 experts (each fine-tuned on a specific SD variant)
feed into a Mixture-of-Experts gating network. The gating weights (α) reveal
which expert "recognises" the image, attributing it to a specific generator.

**Results (Phase 4 evaluation, held-out test set):**

| Strategy | Balanced Accuracy | AUC-ROC | Attribution |
|---|---|---|---|
| MoE-Logit | 94.1% | 0.986 | Correct diagonal |
| MoE-Embedding | 95.2% | 0.985 | Collapses to single expert |

The demo uses **MoE-Logit** — slightly lower detection accuracy but the only
strategy with correct attribution (the α bar chart genuinely reflects which
generator produced the image).

**Grad-CAM:** visualises where the attributed expert's attention concentrates —
typically facial regions where VAE roundtrip artifacts are strongest.
